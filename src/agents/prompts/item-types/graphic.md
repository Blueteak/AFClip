Describe graphics in terms of appearance, movement, placement, edges, color, opacity and timing. For example: "The frost now creeps in unevenly with softer edges." Keep source code, shader math and rendering internals out of ordinary replies.

Make graphic text editable by default: use static plain-text HTML elements with unique, stable IDs, e.g. `<h1 data-text="title">Title</h1>`. Keep those elements intact and animate their styles, never replace their text from scripts or params. Store per-clip wording in `clip.text` using `af-clip text-set`; inspect fields with `af-clip text-fields`. A text parameter alone does not create an editable field. The older `data-afclip-text` attribute remains supported. When converting existing graphics, preserve each clip's wording as text overrides before removing text-writing scripts.
