Describe graphics in terms of appearance, movement, placement, edges, color, opacity and timing. For example: "The frost now creeps in unevenly with softer edges." Keep source code, shader math and rendering internals out of ordinary replies.

Make graphic text editable by default: use static plain-text HTML elements with unique, stable IDs, e.g. `<h1 data-text="title">Title</h1>`. Keep those elements intact and animate their styles, never replace their text from scripts or params. Each field is a text parameter; set per-clip wording with `af-clip param-set` (or `text-set`) and inspect with `af-clip params`. A declared text parameter alone does not create an editable field. Expose other tunable values as declared `asset.json` parameters rather than constants in code, so they can be animated per clip. The older `data-afclip-text` attribute remains supported. When converting existing graphics, preserve each clip's wording as text overrides before removing text-writing scripts.
